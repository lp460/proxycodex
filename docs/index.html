Local par conception

Vos clés ne voyagent pas dans vos fichiers Codex.

Le routage se fait sur votre Mac via des adaptateurs écoutant uniquement sur 127.0.0.1. Les secrets sont masqués dans les journaux.

  • ✓Dossier privé en permission 0700, fichier de clés en 0600.
  • ✓Aucune clé dans les arguments de processus, profils, catalogues ou fichiers temporaires.
  • ✓Code public et vérifiable, avec sauvegardes avant chaque modification.

Questions fréquentes

Avant d’installer.

ProxyCodex remplace-t-il Codex ?

Non. Il complète Codex en ajoutant des routes vers d’autres fournisseurs. Le provider OpenAI natif reste disponible et peut être restauré en un clic.

Mes outils MCP et apply_patch fonctionnent-ils ?

ProxyCodex traduit les outils Codex en function tools pour les providers compatibles, puis restitue les appels dans leur format d’origine. La qualité d’exécution dépend toujours du modèle choisi.

Où sont conservées mes clés ?

En local sur votre Mac, dans un fichier privé aux permissions restreintes. Elles ne sont ni écrites dans config.toml, ni envoyées à ProxyCodex.

Comment arrivent les nouvelles versions ?

L’application vérifie chaque jour le flux de mises à jour signé. Lorsqu’une version est publiée sur GitHub, elle peut être téléchargée et installée directement.
